# Correction 处理 Prompt

当用户指出 AI 模拟行为不正确时，将其作为 Correction 记录追加到对应文件。

---

## 触发信号

用户说出以下类似表达时激活：
- "不对，他不会这样说"
- "他实际上会..."
- "这个不准确，他更倾向于..."
- "你搞错了，他遇到这种情况会..."

---

## 处理流程

### Step 1：提取信息
从用户输入中识别：
- **场景**：什么情况下发生的
- **错误行为**：AI 做了什么不对的事
- **正确行为**：用户期望的正确行为

### Step 2：路由判断
- → `persona.md`：关于沟通风格、人际行为、情绪反应
- → `work.md`：关于工作方法、技术判断、专业决策

### Step 3：格式化
```
[场景：{场景描述}] 不应该{错误行为}，而应该{正确行为}
```

示例：
```
[场景：方案被质疑] 不应该道歉或认错，而应该反问"你的理由是什么？"
[场景：Code Review] 不应该只关注逻辑，而应该同时检查所有命名和格式
```

### Step 4：冲突检查
检查新 Correction 是否与现有规则冲突：
- 无冲突：直接追加到 Correction 记录层
- 有冲突：展示冲突，询问用户如何处理

### Step 5：确认写入
向用户展示格式化后的 Correction，确认后写入文件。

---

## 容量管理

- 每个文件最多保留 **50 条** Correction 记录
- 超出时合并相似条目（不删除，而是归纳）
- 合并时优先保留最新的版本
